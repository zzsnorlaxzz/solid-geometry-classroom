# 입체도형 연구실 — 드래그 편집

실행: https://zzsnorlaxzz.github.io/solid-geometry-classroom/

삼각기둥·사각기둥·삼각뿔·사각뿔·원기둥·원뿔의 모양과 전개 과정을 직접 조작하는 수업 프로그램입니다.

- 처음 화면을 열거나 입체도형·밑면을 선택하면 **접힌 상태(전개율 0)**에서 시작합니다.
- 삼각형·사각형을 선택하면 각각 한 변의 길이가 6인 **정삼각형·정사각형**으로 시작합니다. 다른 밑면으로 바꿨다가 돌아와도 기본 정다각형으로 돌아갑니다.
- **원기둥·원뿔**은 입체도형 선택에서 고릅니다. 밑면 꼭짓점 편집 대신 **밑면 반지름** 슬라이더가 나타나며, 높이는 기존 세로 슬라이더로 조절합니다. 원기둥은 직사각형과 두 원으로, 원뿔은 부채꼴과 원으로 펼쳐집니다.
- 왼쪽의 **밑면 모양 만들기**에서 꼭짓점 A·B·C·D를 드래그합니다. 삼각형은 점 3개, 사각형은 점 4개입니다. 움직이는 점 이외의 점은 그대로 유지됩니다.
- 밑면의 길이·각도가 함께 달라지며 3D 입체도형과 오른쪽 전개도가 즉시 갱신됩니다. 사각형은 원에 내접하는 형태에 한정되지 않습니다.
- **3D 모델 오른쪽의 세로 높이 슬라이더**를 드래그해 높이를 조절합니다. 위로 올리면 높아지고 아래로 내리면 낮아집니다. 모델 회전과 높이 조절은 서로 간섭하지 않습니다.
- 입체도형에도 편집창과 같은 색의 점을 찍고 그 옆에 A·B·C·D를 표시합니다. 각기둥은 잘 보이는 위쪽 밑면에 점을 표시합니다.
- 기본 3D 시점은 편집창과 같은 좌우·상하 방향을 사용합니다. 편집창의 실제 좌표를 보존하고, 정투영을 사용해 원근 왜곡에 의한 점 순서 변화도 방지합니다. `시점 복귀`로 이 배치로 돌아갑니다.
- 다른 점의 가로선·세로선 가까이 드래그하면 x 또는 y 좌표가 정확히 일치하도록 맞춥니다. 정렬 중에는 점선 안내선이 보입니다. 교차하거나 납작해지는 맞춤은 적용하지 않습니다.
- `모양 초기화`는 현재 밑면만 기본 모양으로 되돌립니다. 높이는 유지되고 전개 진행률은 접힌 상태로 돌아갑니다.
- 왼쪽 3D 모델은 드래그 회전·휠/핀치 확대·축소·시점 복귀가 가능합니다. 면 선택은 왼쪽과 오른쪽에서 연동됩니다. 전개 도중에는 왼쪽을 회전하거나 확대하면 오른쪽도 함께 움직입니다. 완전 전개에 가까워질수록 정면으로 부드럽게 정렬되며, 끝까지 펼치면 전개도 시점과 배율이 고정됩니다. 다시 접으면 연동이 재개됩니다.
- 전개도를 **완전히 펼치면 필기가 자동 활성화**됩니다. 펜·지우개·색·굵기·되돌리기·모두 지우기를 사용할 수 있습니다. 면을 선택할 때는 `면 선택`을 누릅니다. 마우스·터치·펜 입력을 지원합니다.
- 다시 접으면 필기는 숨겨지고 입력이 비활성화됩니다. 같은 도형을 완전히 펼치면 필기가 다시 보입니다. 창 크기가 달라져도 전개도 좌표에 맞춰 필기를 그립니다. 도형·밑면·높이·반지름을 바꾸거나 모양을 초기화하면 필기도 초기화됩니다. 필기는 현재 화면에서만 유지되며 새로고침 후에는 저장되지 않습니다.
- 전개 조작은 드래그 슬라이더 하나입니다. 접힘에서 완전 전개까지 임의의 위치를 지정합니다.
- 길이 숫자 입력과 변 길이 슬라이더는 없습니다. 높이는 모델 옆 슬라이더 하나로 조절하며, 숫자 입력과 3D 높이 손잡이는 없습니다. 저장·길이/넓이 정보·전개 재생 버튼도 없습니다.
- 키보드 접근: 밑면 꼭짓점에 초점을 두고 방향키로 이동합니다. 높이 슬라이더도 방향키와 Home/End로 조작할 수 있습니다. 전개 슬라이더도 키보드로 조작할 수 있습니다.

## 모양 제한

꼭짓점 편집이 가능한 밑면은 **볼록한 삼각형 또는 사각형**입니다. 원기둥·원뿔은 원형 밑면을 사용하며 반지름은 1~4 범위입니다. 변이 교차하거나 일직선에 가까워지는 위치에서는 점이 유효한 경계에서 멈춥니다. 드래그가 큰 폭으로 이동해도 중간 경로를 검사합니다. 오목 사각형은 지원하지 않습니다. 편집 영역 경계, 최소 변 길이·두께·면적과 최대 변 길이 제한으로 극단적인 변형을 방지합니다. 높이는 내부적으로 2~15 범위입니다. 오른쪽에 수치나 설명을 자동 표시하지 않습니다.

각뿔 꼭짓점은 밑면의 면적 중심 바로 위에 있으며, 각 옆면은 밑면의 실제 좌표로 개별 계산됩니다. 각기둥은 밑면에 수직인 옆모서리를 가집니다. 3D 장면에서는 편집창 좌표를 그대로 사용합니다. 전개도는 접힌 상태에서 입체도형과 같은 좌표로 시작하고, 다각형은 첫 변 AB를 기준으로 펼친 뒤 최종 평면으로 정렬합니다. 길이·각도·대응 면은 두 화면에서 동일합니다.

## 개발 및 배포

Node.js 22 이상에서:

```sh
npm ci
npm test
npm run dev
```

http://127.0.0.1:5173 을 엽니다. 종료는 Ctrl+C입니다. 소스 수정 후 다시 빌드하고 새로고침합니다.

```sh
npm run build:pages
```

`src`, `tests`, `docs`를 함께 커밋하면 GitHub Pages가 `main`의 `/docs`에서 배포합니다. 이 버전부터 GitHub와 GitHub Pages에만 변경을 반영합니다. `docs/index.html`은 코드와 스타일을 포함한 단일 파일입니다. `dist/입체도형-수업.html`은 로컬 빌드 산출물입니다. CDN·외부 API·로그인이 필요하지 않으며, WebGL 그래픽 가속을 지원하는 브라우저가 필요합니다.

기하 계산과 제약은 `src/geometry.js`, SVG 편집 입력은 `src/editor.js`, 3D·높이 조절·전개 처리는 `src/main.js`, 전개 좌표와 시점 연동은 `src/presentation.js`, 필기는 `src/annotations.js`, 화면 구조는 `src/ui.js`에 있습니다. 검증 범위는 `검증보고서.md`, 의존성 라이선스는 `THIRD_PARTY_NOTICES.txt`에 있습니다.
