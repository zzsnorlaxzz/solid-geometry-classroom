# 입체도형 연구실 — 드래그 편집

실행: https://zzsnorlaxzz.github.io/solid-geometry-classroom/

삼각기둥·사각기둥·삼각뿔·사각뿔의 모양과 전개 과정을 직접 조작하는 수업 프로그램입니다.

- 왼쪽의 **밑면 모양 만들기**에서 꼭짓점 A·B·C·D를 드래그합니다. 삼각형은 점 3개, 사각형은 점 4개입니다. 움직이는 점 이외의 점은 그대로 유지됩니다.
- 밑면의 길이·각도가 함께 달라지며 3D 입체도형과 오른쪽 전개도가 즉시 갱신됩니다. 사각형은 원에 내접하는 형태에 한정되지 않습니다.
- **3D 모델 위의 노란 ↕ 손잡이**를 드래그해 높이를 조절합니다. 모델 회전과 높이 조절은 서로 다른 입력으로 처리됩니다.
- `모양 초기화`는 현재 밑면만 기본 모양으로 되돌립니다. 높이와 전개 진행률은 유지됩니다.
- 왼쪽 3D 모델은 드래그 회전·휠/핀치 확대·축소·시점 복귀가 가능합니다. 면 선택은 왼쪽과 오른쪽에서 연동됩니다.
- 전개 조작은 드래그 슬라이더 하나입니다. 접힘에서 완전 전개까지 임의의 위치를 지정합니다.
- 길이 숫자 입력, 변 길이 슬라이더, 높이 숫자 입력과 높이 슬라이더를 제거했습니다. 판서·저장·길이/넓이 정보·전개 재생 버튼도 없습니다.
- 키보드 접근: 밑면 꼭짓점에 초점을 두고 방향키로 이동합니다. 높이 손잡이에서는 위/아래 방향키로 높이를 바꾸고 Home/End로 최소/최대로 이동합니다. 전개 슬라이더도 키보드로 조작할 수 있습니다.

## 모양 제한

밑면은 **볼록한 삼각형 또는 사각형**입니다. 변이 교차하거나 일직선에 가까워지는 위치에서는 점이 유효한 경계에서 멈춥니다. 드래그가 큰 폭으로 이동해도 중간 경로를 검사합니다. 오목 사각형은 지원하지 않습니다. 편집 영역 경계, 최소 변 길이·두께·면적과 최대 변 길이 제한으로 극단적인 변형을 방지합니다. 높이는 내부적으로 2~15 범위입니다. 오른쪽에 수치나 설명을 자동 표시하지 않습니다.

각뿔 꼭짓점은 밑면의 면적 중심 바로 위에 있으며, 각 옆면은 밑면의 실제 좌표로 개별 계산됩니다. 각기둥은 밑면에 수직인 옆모서리를 가집니다. 3D 장면에서는 첫 변 AB가 기준 방향이 되도록 밑면을 회전·이동하여 표시합니다. 편집창과 실제 도형의 길이·각도는 동일합니다.

## 개발 및 배포

Node.js 22 이상에서:

```sh
npm ci
npm test
npm run dev
```

http://127.0.0.1:5173 을 엽니다. 종료는 Ctrl+C입니다. 소스 수정 후 다시 빌드하고 새로고침합니다.

```sh
npm run build:pages
```

`src`, `tests`, `docs`를 함께 커밋하면 GitHub Pages가 `main`의 `/docs`에서 배포합니다. `docs/index.html`은 코드와 스타일을 포함한 단일 파일입니다. `dist/입체도형-수업.html`은 오프라인 실행용 파일입니다. CDN·외부 API·로그인이 필요하지 않으며, WebGL 그래픽 가속을 지원하는 브라우저가 필요합니다.

기하 계산과 제약은 `src/geometry.js`, SVG 편집 입력은 `src/editor.js`, 3D·높이 조절·전개 처리는 `src/main.js`, 화면 구조는 `src/ui.js`에 있습니다. 검증 범위는 `검증보고서.md`, 의존성 라이선스는 `THIRD_PARTY_NOTICES.txt`에 있습니다.
