# 입체도형 연구실

실행: https://zzsnorlaxzz.github.io/solid-geometry-classroom/

삼각기둥·사각기둥·삼각뿔·사각뿔의 모양과 전개 과정을 살펴보는 수업 프로그램입니다.

- 밑면은 삼각형 또는 사각형만 선택합니다.
- 삼각형의 세 변, 사각형의 네 변을 각각 2~10cm, 0.1cm 단위로 조절합니다. 숫자 입력과 슬라이더가 연동됩니다. 다른 변을 자동으로 바꾸지 않습니다.
- 가장 긴 변이 나머지 변의 합 이상이면 만들 수 없는 도형이므로 적용하지 않습니다. 숫자는 이전 유효한 값으로 돌아가고 왼쪽에 안내합니다. 슬라이더 범위는 가능한 길이로 제한됩니다.
- 사각형은 네 변만으로 모양을 하나로 정할 수 없으므로, 주어진 변을 순서대로 가진 **볼록한 원에 내접하는 사각형**을 생성합니다. 네 변이 같을 때는 정사각형이지만, 다른 길이를 주면 비정사각형이 됩니다. 임의의 오목 사각형이나 각도 지정 기능은 포함하지 않습니다.
- 밑면 꼭짓점 A·B·C·D를 왼쪽 모델에 표시하여 조절하는 변을 구분합니다. 오른쪽에는 자동 문자나 수치를 표시하지 않습니다.
- 높이는 2~15cm로 조절합니다. 각뿔 꼭짓점은 밑면의 면적 중심 바로 위에 있습니다. 비정규 밑면에 맞추어 각 옆면의 모양이 개별 계산됩니다.
- 왼쪽 3D 모델의 드래그 회전, 휠·터치 확대/축소, 시점 복귀를 지원합니다. 면을 누르면 왼쪽과 오른쪽에서 대응하는 면을 함께 강조합니다.
- **전개 조작은 드래그 슬라이더 하나**입니다. 양 끝은 접힘과 완전 전개, 중간은 해당 진행률입니다. 키보드 방향키·Home·End도 사용할 수 있습니다.
- 판서, 저장, 자동 길이·넓이 계산 정보, 재생·정지·역재생 버튼은 제거했습니다.

## 개발 및 배포

Node.js 22 이상을 설치한 뒤:

```sh
npm ci
npm test
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 종료는 Ctrl+C입니다. 소스를 수정한 뒤에는 다시 빌드하고 새로고침합니다.

```sh
npm run build:pages
```

`src`와 `docs`를 함께 커밋하면 GitHub Pages가 `main` 브랜치의 `/docs`에서 자동 배포합니다. `docs/index.html`은 모든 실행 코드와 스타일을 포함합니다. 별도 CDN·로그인·외부 API가 필요하지 않습니다. `dist/입체도형-수업.html`은 오프라인 실행용 파일입니다. 브라우저에서 WebGL 그래픽 가속을 사용할 수 있어야 합니다.

## 기하 구조

`src/geometry.js`가 입력한 변으로 밑면 좌표를 생성합니다. 삼각형은 세 변에 대한 코사인 법칙을 이용합니다. 사각형은 원에 내접하는 사각형의 대각선 관계를 이용합니다. 각기둥은 실제 밑면의 외각만큼 옆면 연결부를 회전시키고, 각뿔은 각 밑면 변을 축으로 실제 옆면을 회전시킵니다. 모든 중간 상태에서 면의 길이와 면적이 보존됩니다.
