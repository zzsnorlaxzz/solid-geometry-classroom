# 입체도형 연구실

중학교 1학년 겉넓이 수업용 정적 웹 프로그램입니다. 삼각·사각·오각·육각 기둥과 뿔, 직원기둥, 직원뿔을 하나의 메뉴에서 다룹니다. 계정이나 외부 API, CDN이 필요하지 않습니다.

## 가장 쉬운 실행 방법

1. 제공된 `입체도형-수업.html`을 컴퓨터에 저장합니다.
2. 파일을 Chrome 또는 Edge로 엽니다. 인터넷 연결 없이 실행됩니다.
3. 왼쪽 도형 메뉴에서 도형을 고르고 크기와 높이를 조절합니다.
4. `처음` → `펼치기`로 전개 과정을 관찰합니다. 슬라이더로 임의의 지점에 정지할 수 있습니다.
5. 오른쪽 툴바의 펜 아이콘을 누르고 마우스·손가락·펜으로 씁니다.

태블릿에서 로컬 HTML 열기를 제한하는 경우 정적 웹 호스팅 주소를 사용하거나 아래 로컬 서버로 실행합니다. WebGL 그래픽 가속이 필요합니다.

## 소스 프로젝트 실행

Node.js 22 이상을 설치한 뒤 압축을 풀고 프로젝트 폴더에서 터미널을 엽니다.

```sh
npm ci
npm run dev
```

터미널의 `http://127.0.0.1:5173`을 브라우저로 엽니다. 종료는 터미널에서 Ctrl+C입니다. 소스를 고친 경우 다시 빌드하거나 `npm run dev`를 다시 실행하고 브라우저를 새로 고칩니다. 자동 갱신 서버는 아닙니다.

```sh
npm test
npm run build
npm run preview
```

`dist/index.html`과 `dist/assets/`는 일반 정적 호스팅에 올릴 수 있습니다. `dist/입체도형-수업.html`은 모든 런타임 JS와 CSS를 포함하는 독립 실행 파일입니다. 의존성 설치에만 인터넷이 필요하며, 빌드된 프로그램은 네트워크를 사용하지 않습니다. WebAssembly 기반 Rollup으로 빌드하여 네이티브 실행 파일이 제한된 Windows 환경도 지원합니다.

## 수업 조작

- 왼쪽 모델: 드래그 회전, 휠·핀치 확대, +/− 버튼, 시점 복귀. 도형은 실제 길이 비율을 사용합니다.
- 왼쪽 설정: 변 또는 반지름 2–10cm, 높이 2–15cm. 숫자와 슬라이더는 0.1cm 단위로 연동합니다.
- 컨트롤 접기: 설정과 계산을 접고 모델 영역을 넓힙니다. 전개 제어는 남습니다.
- 재생: 펼치기·접기·일시정지·처음·완료·타임라인 조절. 재생 도중에도 슬라이더를 쓸 수 있습니다.
- 면 선택: 왼쪽 모델 또는 오른쪽 선택 도구로 면을 누릅니다. 두 화면에서 대응하는 면을 같은 주황색으로 강조합니다. 밑면 전체·옆면 전체 강조도 가능합니다.
- 수학 정보: 왼쪽에서 길이·높이·밑넓이·옆넓이·겉넓이·계산 과정을 개별 공개합니다. 원 도형은 π/근삿값을 선택합니다. 원뿔의 청록 보조선은 수직 높이, 주황 보조선은 모선입니다.
- 오른쪽: 도형, 판서와 도구 아이콘만 표시합니다. 자동 수치나 설명을 생성하지 않습니다.
- 판서 도구: 선택, 펜, 이동, 네 가지 색, 굵기, 지우개, 실행 취소, 다시 실행, 전체 삭제, 이미지 저장. 노랑은 흰 바탕에서 보이도록 짙은 황색입니다.
- 이동 모드: 드래그 이동, 휠·두 손가락 확대. 왼쪽 체크박스로 필기도 함께 이동할지 선택합니다. 화면 크기 변경 시 기본 연결 모드에서 비율을 맞춥니다.
- 필기는 화면 좌표를 기준으로 독립 저장됩니다. 전개 진행률이나 왼쪽 모델 회전·확대가 필기를 지우거나 이동시키지 않습니다. 전개도 초기화와 필기 삭제도 독립입니다.
- 필기는 브라우저 로컬 저장소에 자동 저장됩니다. 삭제 직전 상태는 `마지막 필기 복원`으로 되돌립니다. 브라우저가 저장소를 차단하거나 데이터를 지우면 복원할 수 없습니다.
- 전개도 PNG: 도형과 판서만 저장합니다. 전체 수업 PNG: 현재 보이는 좌우 화면과 도구를 저장합니다. 스크롤 아래의 숨겨진 정보까지 전부 저장하는 문서 출력 기능은 아닙니다.

## 구조와 수학

`src/geometry.js`가 모든 면과 계산을 생성합니다. `src/main.js`는 Three.js 장면, 카메라, UI, 면 대응, 독립 Canvas 판서와 이미지 내보내기를 관리합니다. `tests/geometry.test.js`는 독립적인 삼각형 면적 계산과 분리축 검사로 기하를 검증합니다.

- 정n각형 밑면: 외접원 반지름 R=a/(2sin(π/n)), 내접원 반지름 b=a/(2tan(π/n)), 둘레 P=na, 밑넓이 B=Pb/2.
- 각기둥: 옆면은 연결 모서리에서 회전하여 일렬 띠로 펴집니다. 두 밑면은 첫 옆면의 서로 반대 변에 붙습니다. L=Ph, S=2B+L.
- 정뿔: 각 옆면은 밑면의 해당 변을 고정축으로 회전합니다. 옆면 높이는 √(h²+b²), L=P√(h²+b²)/2, S=B+L.
- 원기둥: 원주 매개변수 s∈[−πr,πr], k=(1−t)/r에 대해 x=sin(ks)/k, z=(1−cos(ks))/k. k→0에서는 x=s,z=0으로 처리합니다. ∂(x,z)/∂s의 길이는 항상 1입니다. 최종 직사각형은 정확히 2πr×h이며, 두 원은 서로 반대 긴 변에 접합니다.
- 원뿔: l=√(r²+h²), q=r/l+(1−r/l)t, 고유 매개변수 ρ∈[0,l], φ∈[−π,π]에 대해 x=ρq sin(φr/(lq)), y=ρq cos(φr/(lq)), z=(l−ρ)√(1−q²). 표면 계량 dρ²+(ρr/l)²dφ²가 t와 무관합니다. t=1에서 반지름 l, 중심각 2πr/l의 부채꼴이 됩니다. 호 길이 2πr, 넓이 πrl입니다. 밑면 원은 호 중앙에서 바깥쪽으로 한 점 접합니다.

곡면은 원주 방향 256분할로 렌더링합니다. 수학 데이터와 공식은 해석식으로 계산하고, 화면의 원호만 작은 직선으로 근사합니다. 접힘 중간 상태의 자기 교차나 밑면의 회전은 실제 종이의 물리적 움직임을 재현하는 시뮬레이션이 아닙니다. 면과 곡면 좌표의 연속성, 길이·면적 보존, 정확한 최종 전개도를 우선합니다.
